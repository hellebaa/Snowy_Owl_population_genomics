# Relatedness Metadata

## Online Data Table: full pairwise KING kinship

- `online_data_full_pairwise_KING_kinship.csv`

This table contains all pairwise KING kinship estimates from the autosomal
pruned SNP dataset used for relatedness assessment. It is intended as an
online/repository data table, not as a manuscript supplementary table.

Columns include the two sample identifiers, short sample IDs, population labels,
the KING kinship estimate, whether the pair exceeds the provisional reporting
threshold of 0.03, and the curated sample-level relatedness flags.

The manuscript-facing Supplementary Table S3 contains only pairs with KING
kinship > 0.03.
