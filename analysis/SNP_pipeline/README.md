Snowy Owl Variant Processing Pipeline (FINAL)

========================================
INPUT DATA
==========

* Whole genome resequencing (~30× coverage)
* Reference genome: chromosome-level Snowy Owl assembly
* Alignment: BWA-MEM
* Variant calling: GATK HaplotypeCaller (GVCF mode)

========================================
PRIMARY GATK PIPELINE
=====================

1. Read mapping

   * bwa mem

2. BAM processing

   * sorting and indexing: samtools
   * duplicate marking: Picard/GATK

3. Variant calling

   * GATK HaplotypeCaller (per sample, GVCF mode)

4. Joint genotyping

   * GenomicsDBImport
   * GenotypeGVCFs

5. SNP extraction

   * GATK SelectVariants

6. GATK hard filtering
   Variants were filtered using:

   * QD < 2.0
   * FS > 60.0
   * SOR > 3.0
   * MQ < 40.0
   * MQRankSum < -12.5 (when present)
   * ReadPosRankSum < -8.0 (when present)
   * BaseQRankSum < -6.0 (when present)

7. PASS variants retained
   Output:

   * step2.PASS.vcf.gz

========================================
AUTOSOMAL SNP FILTERING PIPELINE
================================

STEP 1: Sample renaming

* Sample identifiers standardized across analyses

STEP 2: Chromosome splitting

* Autosomes
* SUPER_Z
* SUPER_W

Autosomal analyses were performed using autosomes only.

STEP 3: Genotype filtering
Genotypes were converted to missing if:

* DP < 5
* GQ < 20

Output:

* autosomes.step5.GTfiltered.vcf.gz

STEP 4: Tag recalculation
The following tags were recalculated after genotype filtering:

* AC
* AN
* MAF
* F_MISSING

STEP 5: Site filtering
Autosomal SNPs retained if:

* F_MISSING ≤ 0.20
* MAF ≥ 0.02

STEP 6: Contamination filtering
The following samples were removed based on contamination assessment:

* GRL04_merged_X14
* SKW02_merged_X22

STEP 7: Final tag recalculation
AC, AN, MAF and F_MISSING recalculated after sample removal.

========================================
PIXY ALL-SITES DATASET
======================

To obtain unbiased estimates of diversity statistics, callable
invariant sites were generated separately from the GATK all-sites
genotyping output.

Invariant sites:

* retained as GATK all-sites records with no alternate allele (`ALT=.`)
* no site-level invariant-site QUAL filter
* invariant genotypes with DP < 5 set to missing
* contaminated individuals removed
* autosomes only

Output:

* SnowyOwl_autosomes_invariant_noQUAL_DP5.vcf.gz

Autosomal invariant-site records:

* 1,145,122,611

The final pixy input VCF was generated by concatenating:

* SnowyOwl_autosomes_snps_curated50_missing20_noMAF.recalc.vcf.gz
* SnowyOwl_autosomes_invariant_curated50_noQUAL_DP5.vcf.gz

Output:

* SnowyOwl_autosomes_allSites_curated50_noQUAL_DP5_noMAF.vcf.gz

Total autosomal all-sites records:

* 1,146,905,667

The pixy ALL run used 1,101,113,709 callable sites after pixy's
statistic-specific missing-data accounting.

The SNP component retained biallelic SNPs after genotype filtering, subsetting
to 50 curated high-quality individuals, and F_MISSING <= 0.20. No
minor-allele-frequency filter was applied. The same curated no-MAF all-sites VCF
was used for nucleotide diversity (π), Tajima's D, FST, and dXY.

Used for:

* nucleotide diversity (π)
* Tajima's D
* FST
* dXY

with pixy v2.0.0.
