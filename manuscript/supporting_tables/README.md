# Supporting Table Drafts

Draft supporting tables are generated by `scripts/11_supporting_tables.R`.

These files are intended as manuscript-facing, compact tables. Large window-level or segment-level outputs should remain repository/archive tables rather than being pasted into the supporting information.

Manual curation copies are stored in `curated/`. Edit the files in `curated/`
when preparing manuscript-ready tables; the generated `Table_S*.csv` files in
this folder may be overwritten when `scripts/11_supporting_tables.R` is rerun.

## Proposed Tables

### Table S1. Sample metadata and analysis inclusion overview

One row per Snowy Owl sample, including sample identifiers, sampling region, collection year, observed/field sex, age, and tissue. Abbreviations: M = male, F = female, NA = unavailable or unknown; MU = muscle, BL = blood, BF = blood feather, FE = feather.

Manual check: verify sample identifiers, collection years, sex calls, and whether all individual-level metadata can be made public.

### Table S2. Sequencing and genotype QC summary

Sample-level sequencing and genotype QC metrics, including autosomal mean depth, missingness, heterozygosity, observed/field sex, genomic sex, final interpreted sex, QC flags, relatedness/contamination decisions, and inclusion flags for PCA, pixy, ROH, and GONE analyses. Abbreviations: M = male, F = female, NA = unavailable or unknown; T = included/true, F = excluded/false.

Manual check: confirm the final wording of QC flags and thresholds, especially for high-missingness samples retained in some analyses but excluded from others.

### Table S3. Pairwise KING kinship estimates above the reporting threshold

Pairwise KING kinship estimates greater than 0.03, generated with PLINK 2.00a3.7 from the LD-pruned autosomal SNP dataset using `--make-king square`.

Manual check: confirm that 0.03 is the preferred reporting threshold. Full pairwise KING kinship results are stored as an online/repository data table in `data/metadata/relatedness/online_data_full_pairwise_KING_kinship.csv`.

### Table S4. PCA dataset summaries

Summary of PCA datasets, including GATK autosomal PCA and ANGSD pseudohaploid PCA inputs, sample filters, site filters, retained sample counts, retained site counts when available, and PC1/PC2 variance explained.

Manual check: confirm exact GATK SNP counts and LD-pruning details if those should be reported precisely. The ANGSD autosomal PCA with QC-filtered samples and MAC >= 3 is the recommended Figure S2 candidate.

### Table S5. Pairwise FST and dXY among sampling regions

Pairwise summaries of window-based FST and dXY among sampling regions. FST summaries use pixy window estimates and dXY is summarized as a site-weighted mean across windows.

Manual check: confirm population labels and rounding. This table can support the main Figure 1 pairwise differentiation panel.

### Table S6. Genome-wide diversity summaries by macro- and microchromosomes

Nucleotide diversity and Tajima's D summarized separately for macrochromosomes and microchromosomes, including number of windows, callable sites, unweighted mean, callable-site-weighted mean, and median values.

Manual check: confirm the macro/microchromosome definition in the table legend and final text.

### Table S7. Centromere/pericentromere diversity summary

Nucleotide diversity and Tajima's D summarized for windows classified as putative centromere, pericentromere, or genomic background, including the callable-site threshold, number of windows, callable sites, unweighted mean, callable-site-weighted mean, median, minimum, and maximum values.

Manual check: emphasize that centromere annotations are available for only a subset of chromosomes and that callability/mappability may differ among regions.

### Table S8. Individual ROH summary

Individual-level ROH burden, including total number of ROH, total ROH length, FROH, and FROH by length class.

Manual check: confirm the autosomal genome size used for FROH and the ROH length-class definitions in the methods.

### Table S9. Regional ROH summary

Regional and all-sample summaries of ROH burden, including mean/median FROH and ROH counts.

Manual check: decide whether to emphasize regional summaries given the panmictic interpretation, or use the all-sample row as the main interpretive summary.

### Table S10. Chromosomes used for GONE demographic inference

Snowy Owl chromosomes retained for GONE analyses based on one-to-one synteny with chicken, absence of fusion/fission relative to the homologous chicken chromosome, comparable acrocentric chromosome morphology, and availability of chromosome-specific chicken recombination-rate estimates.

Manual curation required: add the homologous chicken chromosome and chromosome-specific recombination rate for each retained Snowy Owl chromosome. Also resolve whether the 6.63 cM/Mb value should be described as an arithmetic mean or a length-weighted mean; the current project GONE README says length-weighted mean, while the draft legend pasted into the thread says arithmetic mean.

### Table S11. GONE dataset and sensitivity summary

Summary of the primary high-depth GONE run and sensitivity analyses, including sample set, variant filter, generation time, present year, and key Ne summary statistics.

Manual check: decide whether implausible all64 sensitivity runs should remain in the formal supporting table or be described only in text/repository output.
