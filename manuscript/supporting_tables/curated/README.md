# Curated Supporting Tables

These files are manual-curation copies of the generated supporting-table drafts
in `manuscript/supporting_tables/`.

Edit these copies when preparing manuscript-ready supplementary tables. The
parent-folder `Table_S*.csv` files are generated by
`scripts/11_supporting_tables.R` and may be overwritten when that script is
rerun.

Suggested workflow:

1. Curate table content, legends, rounding, and manuscript wording here.
2. Keep notes on any manual edits that cannot be regenerated automatically.
3. If a manual correction should become reproducible, update
   `scripts/11_supporting_tables.R` and regenerate the draft table.
